# SitterPay Website

This repository contains the official website for SitterPay, a mobile app that helps parents calculate babysitting fees and manage babysitters.

## Website Structure

- `index.html` - Main landing page
- `privacy.html` - Privacy Policy page
- `terms.html` - Terms of Service page
- `styles.css` - Main stylesheet
- `script.js` - JavaScript functionality
- `images/` - Directory for website images

## Features

The SitterPay website includes:

1. **Landing Page**
   - Hero section with app description
   - Feature highlights
   - How it works section
   - Download links
   - Testimonials
   - Contact form

2. **Legal Pages**
   - Privacy Policy
   - Terms of Service

## Design

The website uses a modern, responsive design with:
- Primary color: #C38DFF (purple)
- Secondary color: #FFE4FA (light pink)
- Accent color: #8B2D8B (dark purple)
- Font: Poppins

## Development

To work on this website locally:

1. Clone the repository:
   ```
   git clone https://github.com/dbmiller65/SitterPay-website.git
   ```

2. Open the project in your preferred code editor

3. View the website by opening `index.html` in a web browser

## Deployment

The website is currently deployed at: [https://sitterpay.com](https://sitterpay.com)
